# Python Learning Lab

A growing collection of beginner-friendly Python examples, practice prompts, and small projects.

**Maintained by:** Kelvin Kilonzo  
**Focus:** Python fundamentals, problem-solving, and writing readable code.

## What is here?

| Folder | Topic | Contents |
| --- | --- | --- |
| [week-00-basics](week-00-basics/) | Basics | Variables, strings, input, functions |
| [week-01-conditionals](week-01-conditionals/) | Conditionals | Comparisons and branching |
| [week-02-loops](week-02-loops/) | Loops | Planned practice prompts |
| [mini-projects](mini-projects/) | Small projects | Ideas to implement and document |

The included examples are **starter learning material**, not evidence of completed coursework or independently delivered software. More exercises and project reflections will be added as they are actually completed.

## Run an example

1. Install Python 3.
2. Clone this repository or download the example files.
3. Open a terminal in the repository directory.
4. Run, for example:

```bash
python week-00-basics/greetings.py
python week-01-conditionals/grade_checker.py
```

On systems where `python` is not mapped to Python 3, use `python3`.

No third-party packages are required for the starter examples.

## Learning approach

- Practice one concept at a time.
- Run the code and change inputs to explore different outcomes.
- Write new solutions independently before reviewing examples.
- Document mistakes, improvements, and lessons learned.
- Publish finished mini-projects with instructions and sample output.
