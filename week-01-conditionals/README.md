# Week 01: Conditionals

Starter example for `if`, `elif`, `else`, comparisons, and input validation.

Run `python week-01-conditionals/grade_checker.py` from the repository root.

The labels are illustrative programming categories, **not** an institution's grading scale.

## Try it yourself

- Change the categories and thresholds.
- Add a check for a special score.
- Explore what happens with negative numbers or nonnumeric input.
